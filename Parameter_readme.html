RobuLingo Parameter Reference

Cloudflare download criteria

The app fetches start curricula from Cloudflare (R2 buckets) via ApiClient.loadStartCurriculum. This method builds the URL list in _startCurriculumCandidates, tries both the virtual host and the /file API, and falls back to start_curriculum_a.json if allowDefaultFallback is true.

Curricula that should only contain items with JSON, language audio, and an image are filtered through _pickCompleteEntries. That helper checks each UUID with _isCompleteStartItem, which double-checks the catalog, audio (via hasAudioForLang), and images before including the entry.

The constant startCurriculumWindowSize in lib/constants.dart controls how many entries are kept after this filtering. Adjust it there (or the fallback flag passed to loadStartCurriculum) if you want larger/smaller downloads.

The Cloudflare hosts themselves are defined in lib/constants.dart (curriculumBucketVirtualHost, curriculumBucketPathBase). Changing them reroutes every download.

Distractor selection relative to target

Trials are built inside TrialBuffer (see lib/logic/trial_buffer.dart). For each new target, the controller prefers distractors located within a ±5-item vicinity (the _vicinityWindow constant), excludes the same uuid or identical images, and expands outward only if no valid candidates appear in the first 5 positions.

Review trials are inserted every reviewInterval items (lib/constants.dart). They use the same vicinity rules but only consider previously presented targets.

To adjust the balance between locality and variety, tweak _vicinityWindow, the logic inside _pickDistractor, or reviewInterval.

Mother-tongue text display

The UI only renders the native-language string when the learner selected a mother tongue in NativeLangSelector and the current item contains a nativeText (this happens during loadItem when nativeLang differs from the target language).

The visibility gate lives in _shouldShowNative in lib/app/robulingo_app.dart. It returns true only if nativeLang is set, nativeText is not empty, and nativeSeenCounts[item.uuid] < 1 (the counter is bumped in _gotoNextTrial). Change that logic or the counter to show the translation more than once, to delay it, or to base it on another flag.

Hexamatch duel logic

Hexamatch is powered by HexagonController in lib/logic/hexagon_controller.dart. Calling applyPlayerStep(correct: bool) advances the hero along the hex grid, while _scheduleRivalMove() and applyPlayerStep simulate the rival race with configurable probabilities.

Forward/backward movement depends on the grid neighbors, the current delta, and the _chooseForwardWithFallback / _chooseVerticalOrLeft helpers to prevent double backsteps. The rival pacing parameters (rivalSigma, rivalCoupledProb, rivalMaxProbBase, moods, idle boosts, etc.) are constructor defaults of HexagonController.

Change any of those constructor parameters or the move-choosing helpers inside hexagon_controller.dart to influence duel difficulty, trail behavior, or win detection.

Seed handling

Seeds are loaded from start_curriculum_a.json by _loadSeeds (see lib/app/robulingo_app.dart). The method steps through the file, checks each UUID for language audio via api.hasAudioForLang, and loads the full ItemData only when the audio exists.

The constant seedCount in lib/constants.dart limits how many seed entries are pulled; it is currently set to zero, so no seeds are added. Increase the constant or change the hard-coded file to use a different start curriculum.

Loaded seeds are appended via trialBuffer.addNewItems, so their distractor logic and review rules behave exactly like regular items.
