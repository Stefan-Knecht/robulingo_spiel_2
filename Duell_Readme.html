Duell Logik (Rival)

Diese Datei beschreibt die Rival-Logik im Hexa-Duell. Ziel: nachvollziehbare, steuerbare Gewinnchancen mit sichtbaren "Streaks/Launen", ohne starres Rubber-Banding.

Kurzer Ablauf

Player Trial -> correct? -> lastTenResults ----+
                                              |
diff = rivalProgress - youProgress --------+  |
                                           |  |
idleDays (Logs) -> idleBoost ----+         |  |
                                |         |  |
mood (Markov) -> moodOffset -----+         |  |
                                           v  v
                     pCorrect = f(baseProb, catchup, moodOffset, idleBoost)
                                           |
                                           v
                                  Rival move (forward/side/back)

Mood / Launen (Variante B)

Der Rival wechselt zwischen diskreten Modi. Jeder Modus verschiebt die Trefferwahrscheinlichkeit. Die Modi bleiben mehrere Zuege, dadurch entstehen Streaks. 

[slacking] <--> [steady] <--> [hot]
   ^             ^             ^
   | stayProb    | stayProb    | stayProb
   +---- idleBoost bias -> mehr Wechsel nach oben bei Inaktivitaet

Formel (vereinfacht)

baseProb = coupledProb              (fruehe Phase, an Spieler gekoppelt)
baseProb = base + slope * accuracy (spaeter, aus letzten 10 Antworten)

catchup = 1 / (1 + exp((rivalProgress - youProgress) / sigma))

boosted = clamp(baseProb + moodOffset + idleBoost, 0..1)
pCorrect = minProb + (boosted - minProb) * catchup
minProb = minProbRatio * boosted

Idle / Rival Training

idleDays wird aus den lokalen Logs berechnet (events.ndjson). Je laenger der Spieler nicht trainiert hat, desto staerker der Rival: 

idleBoost = min(idleBoostMax, max(0, idleDays - idleGraceDays) * idleBoostPerDay)

Monte Carlo

Die Logik ist absichtlich parameterarm und probabilistisch, damit Gewinnchancen simulierbar bleiben. Fuer Simulationen reichen: accuracy-Verlauf des Spielers, diff-Startwert, mood-Parameter und idleBoost. 

# Konstante Accuracy, Rennen bis zum ersten Sieg
python3 tools/rival_sim.py --mode race --runs 5000 --steps 120 --acc 0.8

# Steigende Accuracy (Beispiel A)
python3 tools/rival_sim.py --mode race --runs 5000 --steps 120 \\
  --acc-profile "0:0.65,60:0.8,120:0.9"

# Idle-Boost aktivieren (Rival trainiert bei Faulheit)
python3 tools/rival_sim.py --mode race --runs 5000 --steps 120 --acc 0.8 --idle-days 6
# Plot der Gewinnwahrscheinlichkeit ueber die Schritte
python3 tools/rival_sim.py --mode race --runs 5000 --steps 120 --acc 0.8 --plot

# Plot als Datei speichern
python3 tools/rival_sim.py --mode race --runs 5000 --steps 120 --acc 0.8 --plot --out plot.png

Hinweis: Wenn keine Siege auftreten, erhoehe --steps.
